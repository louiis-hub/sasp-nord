# SASP Nord - Version GitHub Pages

Cette version est prete pour un hebergement gratuit type GitHub Pages.

Fichiers principaux :
- index.html : accueil
- info.html : informations
- recrutement.html : formulaire
- admin.html : espace admin demo
- style.css : styles
- scoring.js : notation
- backend-shim.js : stockage local de demo

Important : backend-shim.js stocke les candidatures dans le navigateur pour que le site fonctionne en demo hors Apps Script. Pour envoyer vers Google Sheets en production, il faudra brancher un endpoint Apps Script ou un autre backend gratuit.
